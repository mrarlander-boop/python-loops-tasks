# Практические задания по циклам на Python

Набор из пяти консольных программ на Python 3, демонстрирующих работу с циклами `for` и `while`, вводом данных и валидацией пользовательского ввода.

## Список заданий

1. **Задание 1. Вывод последовательности** (`task1_sequence.py`)  
   Выводит числа от `1` до `20` с помощью цикла `for`.
2. **Задание 2. Сумма чисел** (`task2_sum.py`)  
   Запрашивает целое положительное число `N` и вычисляет сумму чисел от `1` до `N` с помощью цикла.  
   Пример вывода для `N = 5`: `Результат: 1 + 2 + 3 + 4 + 5 = 15`.
3. **Задание 3. Таблица умножения** (`task3_multiplication_table.py`)  
   Запрашивает число от `1` до `10` и выводит для него таблицу умножения от `1` до `10` (формат: `4 × 1 = 4`).
4. **Задание 4. Подсчёт чётных чисел** (`task4_even_odd_stats.py`)  
   Последовательно считывает 10 целых чисел и определяет количество чётных чисел, количество нечётных чисел и общую сумму.
5. **Задание 5. Игра «Угадай число»** (`task5_guess_number.py`)  
   Загадывает случайное число от `1` до `100` и подсказывает игроку (`«Загаданное число больше»` / `«Загаданное число меньше»`), пока число не будет угадано, после чего выводит количество попыток.

## Структура проекта

```text
python-loops-tasks/
├── cli_utils.py                  # Общие утилиты ввода-вывода и валидации целых чисел
├── main.py                       # Единое интерактивное меню для запуска всех заданий
├── task1_sequence.py             # Задание 1: последовательность от 1 до 20
├── task2_sum.py                  # Задание 2: сумма чисел от 1 до N
├── task3_multiplication_table.py # Задание 3: таблица умножения
├── task4_even_odd_stats.py       # Задание 4: подсчёт чётных, нечётных и суммы 10 чисел
├── task5_guess_number.py         # Задание 5: игра «Угадай число»
└── tests/
    └── test_tasks.py             # Модульные тесты (unittest)
```

## Запуск

Требуется Python 3.10 или выше.

Запуск через единое меню:

```bash
python main.py
```

Запуск любого задания по отдельности:

```bash
python task1_sequence.py
python task2_sum.py
python task3_multiplication_table.py
python task4_even_odd_stats.py
python task5_guess_number.py
```

## Запуск тестов

```bash
python -m unittest discover -s tests -v
```
